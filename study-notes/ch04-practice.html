Question 1
Select one answer

Which of the following statements about Java primitive and reference data types is true?

A

A double can be directly assigned to a float without casting.

B

A boolean can be cast to an int.

C

A String can be assigned to an Object reference variable.

D

A char is a reference data type.

E

An int can store a long value without any explicit casting.

  • A) A double can be directly assigned to a float without casting.

    • This option is incorrect. A double cannot be directly assigned to a float without casting because double has a larger range and precision than a float.

  • B) A boolean can be cast to an int.

    • This option is incorrect. boolean values cannot be cast to int in Java. They are not compatible types.

  • C) A String can be assigned to an Object reference variable.

    • This option is correct. A String is an instance of the Object class, and hence it can be assigned to an Object reference variable.

  • D) A char is a reference data type.

    • This option is incorrect. char is a primitive data type, not a reference data type.

  • E) An int can store a long value without any explicit casting.

    • This option is incorrect. an int cannot store a long value without explicit casting because long has a larger range than int.

Question 2
Select one answer

What is the output of the following code snippet?

public class OperatorTest {
    public static void main(String[] args) {
        int a = 5;
        int b = 10;
        int c = 15;
        int result = a + b * c / a - b;
        System.out.println(result);
    }
}
A

25

B

35

C

20

D

15

Let's break down the expression a + b * c / a - b step-by-step according to the order of operations:

  1. Multiplication and Division are performed first from left to right:

    • b * c = 10 * 15 = 150
    • 150 / a = 150 / 5 = 30

  2. Addition and Subtraction are performed next from left to right:

    • a + 30 = 5 + 30 = 35
    • 35 - b = 35 - 10 = 25

So, the value of result is 25, and the program prints 25.

  • A) 25

    • This option is correct.

  • B) 35

    • This option is incorrect.

  • C) 20

    • This option is incorrect.

  • D) 15

    • This option is incorrect.

Question 3
Select one answer

Which of the following statements about String and StringBuilder is true?

A

StringBuilder objects are immutable.

B

String objects can be modified after they are created.

C

StringBuilder is synchronized and thread-safe.

D

StringBuilder provides methods for mutable sequence of characters.

E

String and StringBuilder have the same performance characteristics for string manipulation.

  • A) StringBuilder objects are immutable.

    • This option is incorrect. StringBuilder objects are mutable, meaning they can be changed after they are created.

  • B) String objects can be modified after they are created.

    • This option is incorrect. String objects are immutable, meaning once a String object is created, it cannot be modified. Any modification results in a new String object.

  • C) StringBuilder is synchronized and thread-safe.

    • This option is incorrect. StringBuilder is not synchronized and is not thread-safe. If synchronization is required, StringBuffer should be used instead.

  • D) StringBuilder provides methods for mutable sequence of characters.

    • This option is correct. StringBuilder provides methods for a mutable sequence of characters, allowing for modification of the object without creating new instances.

  • E) String and StringBuilder have the same performance characteristics for string manipulation.

    • This option is incorrect. String and StringBuilder do not have the same performance characteristics for string manipulation. StringBuilder is generally more efficient for such operations because it is mutable and does not create new instances with each modification.

Answer and explanation adapted from the book’s answer sheet.

Question 4
Select one answer

Which of the following statements about text blocks are true? (Choose all that apply.)

Reviewed note: The book also marks B correct, but text blocks do not preserve all source whitespace exactly.

A

Text blocks can span multiple lines without needing escape sequences for new lines.

B

Text blocks preserve the exact format, including whitespace, of the code as written.

C

Text blocks can only be used within methods.

D

Text blocks automatically trim leading and trailing whitespace from each line.

E

Text blocks require a minimum indentation level of one space.

A is correct. Text blocks support embedded newlines. B is false because line endings are normalized, incidental indentation is removed, and trailing whitespace is processed. C is false: text blocks are not restricted to methods. D is too broad: meaningful leading spaces can remain. E is false: no minimum one-space indentation is required.

Question 5
Select one answer

Which of the following statements about the Math class is true?

A

The Math.round() method returns a double.

B

The Math.random() method returns a random integer.

C

The Math.max() method can only be used with integers.

D

The Math.pow() method returns the result of raising the first argument to the power of the second argument.

E

The Math.abs() method can only be used with positive numbers.

  • A) The Math.round() method returns a double.

    • This option is incorrect. The Math.round() method returns a long when given a double argument and an int when given a float argument.

  • B) The Math.random() method returns a random integer.

    • This option is incorrect. The Math.random() method returns a double value between 0.0 (inclusive) and 1.0 (exclusive).

  • C) The Math.max() method can only be used with integers.

    • This option is incorrect. The Math.max() method can be used with various numeric types, including int, long, float, and double.

  • D) The Math.pow() method returns the result of raising the first argument to the power of the second argument.

    • This option is correct. The Math.pow() method returns the result of raising the first argument to the power of the second argument. Both arguments are of type double.

  • E) The Math.abs() method can only be used with positive numbers.

    • This option is incorrect. The Math.abs() method can be used with negative numbers to return their absolute value, and it works with various numeric types including int, long, float, and double.

1. What is printed?
Integer division · Select one answer
System.out.println(5 / 2.0);

The double operand causes floating-point division rather than integer division.
2. Which declaration compiles without a cast?
Narrowing · Select one answer

The constant 127 fits in byte. The other declarations require narrowing conversions that are not implicit here.
3. What is printed?
Short circuit · Select one answer
int x = 0;
boolean result = false && ++x > 0;
System.out.println(result + ":" + x);

The left operand of && is false, so its right operand is not evaluated and x stays zero.
4. What is printed?
String equality · Select one answer
String a = "java";
String b = new String("java");
System.out.println((a == b) + ":" + a.equals(b));

new creates a distinct object. == compares references; String.equals compares text content.
5. What is printed?
Immutability · Select one answer
String s = "java";
s.toUpperCase(java.util.Locale.ROOT);
System.out.println(s);

toUpperCase returns a String; it does not mutate s. This code discards the returned value.
6. What does "abcdef".substring(1, 4) return?
Substring · Select one answer

The starting index is inclusive and the ending index is exclusive. Indexes 1, 2, and 3 are selected.
7. What is printed?
Mutable text · Select one answer
var b = new StringBuilder("abc");
b.delete(1, 2);
System.out.println(b);

delete uses an exclusive ending index, so only the character at index 1 is removed.
8. What is printed?
Concatenation · Select one answer
System.out.println(1 + 2 + "x" + 3 + 4);

The first addition is numeric. Once a String is reached, subsequent + operations concatenate left to right.
9. Which line compiles when x is a byte?
Compound assignment · Select one answer
byte x = 1;

Compound assignment includes an implicit cast back to the left operand’s type; ordinary addition promotes byte to int.
10. Which statement about a Java text block is correct?
Text blocks · Select one answer

A text block is a String literal form, finalized before Java 21. Escape sequences and indentation processing still apply.
11. Which two primitive types are integral types?
Primitive types · Select 2 answers

char and long are integral types. float is floating-point, and boolean is a distinct non-numeric primitive type.
